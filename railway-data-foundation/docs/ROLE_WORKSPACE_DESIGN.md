## 最小方案与接口权限

一个 Vue 前端，共用布局，Spring Security 会话登录、BCrypt哈希、CSRF、退出及会话身份失效检查。新增账号表复用 `sharing_subject`，普通账号只关联一个同角色启用主体，管理员不关联普通主体。服务端确定身份与操作人；浏览器只显示它，无角色切换。

| 接口组 | 管理员 | 提供方 | 需求方 |
|---|---|---|---|
| 登录/当前身份/退出 | 本人 | 本人 | 本人 |
| 管理账号、主体写入 | 全平台 | 禁止 | 禁止 |
| 主体选项 | 全部 | 本主体 | 本主体及公开资源的提供方安全元数据 |
| 数据源/扫描列表详情及操作 | 全部 | 本来源及扫描 | 禁止 |
| 资源/字段、能力列表详情 | 全部 | 本来源下全部 | 公开目录中的已发布资源及已启用能力 |
| 资源/字段、能力写入 | 全部 | 本来源下操作 | 禁止 |
| 扫描快照/比较、资源历史 | 全部 | 本来源下 | 禁止；不暴露旧私有记录 |
| REST/Kafka申请列表详情与历史 | 全部 | 涉及本主体，只读 | 本需求主体 |
| 新建/编辑草稿、提交申请 | 管理操作 | 禁止 | 本需求主体；提供方须匹配资源真实归属 |
| 最终确认/退回/启用/暂停/权限配置、重试 | 管理操作 | 禁止 | 禁止 |
| 撤回本人申请、停止本人Kafka订阅 | 管理操作 | 禁止 | 仅本需求主体 |
| REST访问凭据及Kafka一次性领取 | 全平台管理 | 禁止 | 仅本需求主体；不改变外部授权条件 |
| 运行事件/追踪/计量 | 全部 | 本来源资源关联摘要 | 本轮不提供平台监管入口 |

没有导出接口；未来新接口默认禁止，必须显式列入角色规则。详情及写操作检查实际编号归属；查询在数据库分页前添加主体范围，分页总数采用同一范围，不读取全表后在前端隐藏。运行追踪整条查询也按资源归属过滤，不允许混合其他提供方摘要。

## 归属与目录

仅 `source_system.provider_subject_id` 保存归属，扫描→来源、资源→来源、能力→资源继承，不重复添加归属字段。提供方创建来源时由认证身份填写，不能选择别人、使用后台环境引用或接管空归属数据。管理员创建可显式选择启用提供方，也可保持无归属；现存记录保持NULL，不批量分配。创建资源核对来源及扫描归属，能力核对资源归属。现有申请/授权不自动重绑。

需求方目录规则：资源 `PUBLISHED`、安全级别“公开”、来源 `ENABLED`；能力还需 `ENABLED/UP`。资源元数据响应增加实际提供方编号供申请绑定，禁止读取来源接口、运行配置、扫描及历史。目录不代表业务访问授权，仍需管理员审批与既有外部凭据校验。无归属存量记录只能管理员维护，不能由提供方接管或由需求方替它随意指定提供方申请。

普通需求方可以签发自己的REST随机访问令牌，但令牌单独不能访问数据，仍须有效关系/策略；Kafka仅在管理员实际配置权限后一次性领取。提供方确认环节仍未实现，本轮不制造按钮或历史成功。
