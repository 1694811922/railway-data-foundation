# Kafka 订阅消费观察接口

本功能接收外部订阅程序主动上报的技术摘要，底座不订阅、不代理、不保存消息内容。不代表业务处理成功、消费位点已提交或 Broker 独立核验的计费数量。

## 身份与领取

原 `POST /api/v1/kafka-subscriptions/{id}/credential` 在一次性领取 Kafka 密码时，同时返回 `consumption_token`。格式为 `rkc_` 加 43 位随机字符，服务端仅保存 SHA-256 摘要。与 Kafka 密码、登录会话、REST 调用令牌及提供服务运维凭据分别使用；不得互换。

数据库 V15 追加上报摘要表和执行记录中的令牌摘要。存量已领取的密码不重新显示，也不自动分配令牌。需要摘要上报时，管理员停止订阅、确认撤权、重新配置权限，再由本申请需求方或管理员一次性领取。重新配置使旧令牌失效。普通查询不会返回上报令牌或摘要。

## 外部上报

`POST /api/v1/kafka-subscriptions/{id}/consumption-reports`

请求头：`Authorization: Bearer <独立上报令牌>`。技术接口不使用登录 Cookie 或登录 CSRF；工作台其他写入接口仍使用会话和 CSRF。服务端由授权编号和专属令牌确定主体、能力及订阅身份，不接受客户端指定归属。

```json
{
  "report_id": "8eaa04d1-b0b2-4e47-8075-4fb83335331e",
  "started_at": "2026-10-10T12:00:00.000Z",
  "completed_at": "2026-10-10T12:00:00.250Z",
  "positions": [{"partition": 0, "offset": 7, "byte_count": 320}]
}
```

时间必须处于授权有效期，精确到毫秒；单批不超过 60 秒，允许最多 5 秒未来时钟误差。报告编号使用小写 UUID。每批最多 100 个分区位点，不能重复；分区、位点、字节数均为非负整数，分区不超过 2147483647，单条和总字节数不超过 128 MiB。允许空报告，此时明确观察到零条；未上报仍是未知。拒绝未知字段、字符串数字、小数及业务载荷。

成功响应继续使用统一结构：

```json
{
  "code": 0, "message": "success",
  "data": {"report_id": "8eaa04d1-b0b2-4e47-8075-4fb83335331e", "records": 1, "bytes": 320, "replayed": false, "received_at": "2026-10-10T12:00:00.500Z"}
}
```

消息条次等于本批位点数量；载荷字节是消息 value 原始字节长度，不含 key、headers 或传输协议开销，空值按零字节。分区位点仅用于报告一致性核对，不代表提交位点。

同一申请、同一报告编号和相同规范化内容重复上报只计一次，`replayed=true` 并保留第一次接收时间；位点顺序不影响重试。相同编号但内容不同返回 409。不同报告中的同一位点会再次计数，因此名称为“观察消息条次”，不能当作去重后的业务记录数。

| 情况 | HTTP 状态 |
|---|---|
| 无令牌、错误令牌、其他申请令牌或未知授权 | 401 |
| 已停止/撤回、过期、主体/来源/资源/能力失效或执行未启用 | 403 |
| 报告字段、时间或数量不合法 | 400 |
| 同一报告编号内容冲突 | 409 |

报告写入与停止/撤回锁定同一授权父记录；停止意图提交后即拒绝新上报，不等待 Broker 协调完成。报告接口不会授予或恢复 Broker 权限。停止、过期之后的延迟重试也拒绝。

## 工作台读取

`GET /api/v1/kafka-subscriptions/{id}/consumption?limit=20&offset=0`

使用真实登录会话；管理员可读全平台，提供方与需求方只能读取涉及本主体的申请。详情编号和总数同时受到主体范围检查。`limit` 为 1–200，`offset` 为 0–1000000 的整数。返回：

```json
{
  "code": 0, "message": "success",
  "data": {
    "grant_id": "KSG_...",
    "summary": {"state": "NOT_REPORTED", "reports": 0, "records": null, "bytes": null, "last_received_at": null},
    "items": [], "total": 0
  }
}
```

收到报告后状态为 `OBSERVED`，返回累计报告数、消息条次、字节数和最近接收时间。累计包括该申请历史订阅身份配置下的报告；停止不删除历史。列表按观察结束时间及报告编号倒序，包含 `report_id / broker_username / grant_version / started_at / completed_at / record_count / byte_count / received_at`，不暴露位点 JSON、令牌或摘要。

## 使用入口与限制

订阅详情中查看“消费观察”，支持刷新、10/20/50 项分页、读取失败清空及重试。真实失败不转换为演示成功；显式演示模式不读取真实摘要。

独立示例的安全启动方式见 [订阅示例](../examples/kafka-demand/README.md)。示例对同一批报告最多进行两次传输尝试；失败时提示“未确认”，不重新读取业务数据补偿。尚无持久补报队列、进程恢复、业务幂等处理、消费窗口统计、积压统计、完整分布式追踪或消费计费。主动上报只能证明接收了该订阅身份的声明，不能独立证明声明真实。
