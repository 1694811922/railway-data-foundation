# 资源详情工作台（2026-10-04）

本轮完善V0.1/V0.2已有资源详情前端。没有修改Java、Provider、数据库结构或迁移；V0.3保持暂停。

## 页面行为

进入“资源目录 → 查看”：基本信息保持原有展示；字段与能力各自加载、筛选、分页和重试。无需新增后端聚合接口。

| 功能 | 行为 |
|---|---|
| 字段检索 | 关键词同时匹配字段名、业务名称、类型、业务描述及技术注释；组合主键/时间标记和敏感等级 |
| 字段数量 | 展示已读取/匹配数量、主键数和时间字段数；每页10/20/50项，筛选重置页码，数据缩小时修正页码 |
| 关联能力 | 按名称/编号/路径/主题等关键词、类型、状态和健康状态组合筛选，10/20/50项分页 |
| 管理入口 | “管理关联能力”进入能力目录并携带当前资源编号；只有已发布资源可“注册能力” |
| 独立读取 | 字段成功即可查看和编辑，不等待能力请求完成；重新加载某个区域不重读其他区域 |
| 读取失败 | 清空该区域旧数据、显示错误、可单独重试；数量显示“—”；真实读取失败不借用演示结果 |
| 数据归属 | 检查当前资源编号、字段/能力编号、重复编号以及真实/演示模式；拒绝错配结果 |
| 字段保存 | 校验当前资源、前端版本、字段归属与数据模式；提交体只有4项业务属性，输入和关闭按钮在提交时锁定 |
| 写入失败 | 保留输入，不模拟成功；超时或断网提示刷新确认，不自动重发 |
| 切换资源 | 关闭旧编辑弹窗、重置筛选；旧读取/字段保存/发布响应不覆盖或刷新新资源，也不导航回旧页面 |
| 页面退出 | 废弃旧响应；已发往后端的写入不会因此撤销，返回原资源应刷新确认 |

字段和能力接口现阶段返回完整关联列表，显示分页与筛选在前端完成，未新增后端分页接口。筛选条件暂不写入网址。基本信息、字段及能力是独立请求，不能视作事务快照；前端编辑版本检查防止使用已变化的页面上下文，不替代服务端并发控制。健康状态来自最近验证，详情页不发起业务查询或实时探测。
